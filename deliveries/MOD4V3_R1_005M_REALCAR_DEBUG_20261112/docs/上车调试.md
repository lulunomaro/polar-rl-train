# 电控接车调试顺序

本包已完成模型导出、训练观测/控制链对齐和同模型ONNX仿真回放。它没有实车测量记录。当前交付对象是MOD4v3 HW300N60 R3；先核对实际机械、气弹簧和电机与包内plant/model_parameters及legacy参数一致。不要把这份权重配给旧September MOD4模型或旧100Hz策略配置。

1. **离线跑通包。** 安装 `requirements-debug.txt`，运行 `python tools/preflight.py`、`python runtime/infer.py --state examples/bench_input.json`。前者验证文件、模型和金样，后者只打印策略、目标和Nm。bench_input是CAD原生默认角的接口样例，不是实车待机姿态，也不保证零动作/零力矩。
2. **接好轴和单位。** 机械卸载/现有调试支架上逐路确认曲柄、髋、轮的顺序。用 `examples/golden_vectors.json` 的16组输入检查固件组观测、策略动作和目标。允许float32累计误差，CPU实测误差约1e-5；位置目标和Nm在800个真实训练样本对齐中吻合。
3. **填写实车标定。** 将 `config/hardware_calibration.template.json` 复制成 `config/hardware_calibration.json`。逐路记录CAN ID、反馈与Nm单位换算、正方向及编码器参考点，记录IMU板到机身的旋转。原生默认角见接口表；若在该参考姿态测得raw_ref，计算 `raw_zero=raw_ref-sign*position_units*q_ref`，不能直接把raw_ref当原生q=0。
4. **校验最基本的符号。** 物理关节沿模型正向增加0.05rad，canonical反馈应增加0.05rad；角速度+1rad/s应在观测相应槽增加0.1，机身绕+Z转1rad/s应在gyro_z槽出现+0.5；平放重力为[0,0,-1]；高度命令0.28m对应观测1.4。正Nm应驱动对应模型正向，不能只修观测符号却不修输出符号。
5. **标定完成再检查配置。** 实测确认后填verified及人员/时间，执行 `python tools/preflight.py --real-enable --hardware-calibration config/hardware_calibration.json`。该命令只检查完整性和配置，不会发电。当前随包模板verified=false，按预期不能通过真实使能检查。
6. **首次策略接管。** 用已经有轮支承、接近正常站姿的状态，先给vx=0、vy=0、wz=0、高度0.28m。保留整车原急停/断联停机和输出使能。观察姿态、轮向、腿向、Nm、目标/反馈及50Hz/100Hz时间戳；不要先从任意趴地姿态启动无人看管的自动起身。
7. **先低速后扩大。** 先试±0.3m/s，稳定后扩到±0.5、±1.0及原任务范围；旋转、两高度单独验证后再组合。保持原模型配方，不用临时改kp或观测缩放来掩盖方向、零位错误。所有变更需和本包合同对照并记录。
