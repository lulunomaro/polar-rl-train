## 一、Windows播放器

1. 将整个压缩包解压到可写目录；不要在压缩包内直接运行。
2. 安装 **Python 3.12 64位**，安装时保留Python Launcher和Tcl/Tk。
3. 首次双击 `SETUP_WINDOWS.bat`。它在包内创建 `.venv` 并按 `requirements.txt` 安装依赖，需要联网。已在本机Python 3.12.14、NumPy 2.3.5、ONNX Runtime 1.30.0、MuJoCo 3.14.0核验。
4. 双击 `CHECK_PACKAGE_WINDOWS.bat`，看到文件校验和推理PASS后，双击 `START_WINDOWS.bat`。

首次加载全场会需要一些时间。初始暂停，按 **P** 开始。点击驾驶面板或仿真窗口后再操作；窗口失去焦点会归零驾驶输入。

| 操作 | 按键 |
|---|---|
| 前进／后退 | W／S，松手停车 |
| 左转／右转 | A／D |
| 停车并回普通驾驶 | 空格／X |
| 普通驾驶 | N |
| 跳跃请求 | J；0.8秒请求，首次会先普通站立1秒 |
| 恢复 | K |
| 左／右自旋 | Z／B，目标±4rad/s |
| 开始／暂停 | P |
| 复位 | R |
| 下一个起点 | F；也可用路线下拉框 |
| 平地／跳跃／起伏／中心岛起点 | 1／2／3／4 |
| 全场俯视／跟随机器人 | M |

关闭任一窗口可退出。运行状态和错误写在 `player/rm7v7_moe_runs/<本次编号>/`；它们由运行时生成，包中未混入旧日志或锁文件。

本包附带原RM7v7场地XML、实际引用的机器人和场地网格、重置姿态以及控制适配器，采用相对路径。无需原工作区或原电脑目录。模型和场地资产有体积，建议保留至少2GiB空闲空间。

## 二、在自己的程序中推理

只做推理时，可使用轻量策略包，或从完整版保留 `policy/`、`infer.py` 和 `requirements_policy.txt`。安装 `requirements_policy.txt` 后运行：

```python
from infer import HybridMoE
import numpy as np

policy = HybridMoE()
obs = np.zeros(35, dtype=np.float32)
obs[3] = 0.25 * 5.0
obs[9] = -1.0
obs[28] = 1.0                  # 普通模式
action = policy(obs)            # [1, 6]，仅是静态示例
```

生产使用需要每个控制周期提供真实状态；示例中的零状态不能替代传感器和关节观测。ONNX使用CPUExecutionProvider，不需要安装PyTorch。可用 `python infer.py` 检查示例推理。

组合模型：`policy/hybrid_moe.onnx`；输入 `observation` 为float32 `[batch,35]`，输出 `action` 为 `[batch,6]`，已裁剪至±6。还附有五个单独专家ONNX：`E0.onnx`、`W35.onnx`、`H1.onnx`、`E2.onnx`、`E3.onnx`；单专家输出是未裁剪的确定性均值，调用者需要裁剪。STD只属于原训练状态，部署不采样随机动作。

### 35维观测，索引从0开始

| 索引 | 内容 |
|---|---|
| 0–2 | 机体系指令vx、vy、wz；播放器vy固定0 |
| 3 | 高度指令 ×5 |
| 4–6 | 机体系角速度 ×0.5 |
| 7–9 | 机体系投影重力，静止正立为[0,0,-1] |
| 10–13 | 左曲柄、左髋、右曲柄、右髋位置，rad |
| 14–15 | 保留位置项，播放器固定0 |
| 16–19 | 同四关节速度 ×0.1 |
| 20–21 | 左／右轮速度 ×0.1 |
| 22–27 | 上一控制周期的六维裁剪动作 |
| 28–34 | 七维模式one-hot，每次只能一项为1 |

模式0→原E0/W35门控；模式3→E3；模式4→H1；模式6为本播放器的E2自旋别名。组合模型会将E2输入的模式改写为普通模式。其它模式沿用原普通门控回退；本包没有新增楼梯、低矮通过等技能资格。物理训练中的模式语义不能直接等同播放器的模式6别名。

### 六维动作与控制

动作顺序为 `[左曲柄, 左髋, 右曲柄, 右髋, 左轮, 右轮]`，不是六路电机扭矩。前四维乘 `[0.5,0.5,0.5,0.5]` 得关节位置目标；后两维乘10得轮速目标。需要原差动限位、PD和力矩速度包络，完整实现见 `player/sim_runtime.py` 的 `action_to_torque()`，参数见 `player/runtime_config.json`。

播放器采用100Hz策略、0.5ms MuJoCo物理步、腿PD60/2、轮速增益0.6，无额外航向扶正辅助；保持原播放器配方。接到其它仿真或硬件时，必须匹配关节轴向、顺序、单位和适配器；不能直接把ONNX输出发送为扭矩。
