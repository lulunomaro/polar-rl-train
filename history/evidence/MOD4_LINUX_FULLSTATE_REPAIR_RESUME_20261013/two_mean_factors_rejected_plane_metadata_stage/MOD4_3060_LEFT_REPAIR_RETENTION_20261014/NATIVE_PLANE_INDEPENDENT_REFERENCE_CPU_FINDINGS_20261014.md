The public Omni 110.1 source provides an independent explanation for the tiny Plane tilt. It is not a change to the original 1e-6 ground limit or a pass for the failed V6 full case.

For a standalone collider, `Collision.cpp:1567` creates a static actor with the USD world position and rotation, then explicitly resets the shape-local position and rotation. For an axis-Z Plane, `UsdInterface.cpp:3141` installs shape-local `PxQuat(h,0,h,0)`, where the constructor is **x,y,z,w** and `h=sqrt(2.0f)/2.0f`. `NpShape.cpp:367` normalizes this local pose. [Primary Omni 110.1 source](https://github.com/NVIDIA-Omniverse/PhysX/blob/517a0073715120e114ee055b63b26c95e00d9039/omni/ovruntime/source/omni.physx/plugins/usdInterface/UsdInterface.cpp), [PhysX normalization source](https://github.com/NVIDIA-Omniverse/PhysX/blob/517a0073715120e114ee055b63b26c95e00d9039/physx/source/physx/src/NpShape.cpp).

The scalar float32 calculation gives `h=0.7071067690849304`, then normalized h `0.7071068286895752`. `Gu::getPlane` computes its normal using the world quaternion's `getBasisVector0`, and computes `d=-world_position.dot(normal)`. With an identity actor, this independently produces `(1.1920928955078125e-7,0,1.0000001192092896)`. The CPU component calculates this reference before reading any hits. Against the saved failed V6 data, all 82 normals, distances and returned positions match this source reconstruction exactly; the maximum distance from the independently represented plane is 0.367157 micrometers. [Plane equation implementation](https://github.com/NVIDIA-Omniverse/PhysX/blob/517a0073715120e114ee055b63b26c95e00d9039/physx/source/geomutils/src/GuInternal.cpp), [quaternion arithmetic](https://github.com/NVIDIA-Omniverse/PhysX/blob/517a0073715120e114ee055b63b26c95e00d9039/physx/include/foundation/PxQuat.h).

`get_rigidbody_transformation` reads `actor->getGlobalPose()`. It therefore excludes the separate shape-local axis fixup. The actual Python stub exposes this actor getter but no shape-local pose getter. No bridge or GPU package has been produced here.
