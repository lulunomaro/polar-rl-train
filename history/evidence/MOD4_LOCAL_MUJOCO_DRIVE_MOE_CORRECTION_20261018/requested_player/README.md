## 以下为2026-10-08原独立路段交付记录

双击 `START_WASD.bat`。本包固定使用下载时4090实际trainer自己完整保存的 `model_30900`，不是目录最高编号猜测，也不是预检权重。它来自S2 E0 D5第二块，尚未正式行为审查。

点击驾驶面板或MuJoCo窗口后，按住W/S前后走、A/D左右转，松手停车。空格/X停车、R复位、F切换起点、P暂停；1选平地，2选绿色RM起伏路入口，3选蓝色缓坡，4选紫色轻度练习路。鼠标拖动观察，滚轮缩放。初始速度0.6m/s，面板可调0.1–1.5m/s。窗口失去焦点时归零，关闭任一窗口退出本次试玩。

绿色路按用户提供的 **RMUC2026_V2.0.0.stp** 起伏路CAD重建，10个凸起，名义高度 **70mm**、相邻峰间距 **240mm**；不是简单把旧正弦波放大。使用已有CAD碰撞三角面逐点向下投射生成高度场，避免MuJoCo凸包把波谷填平。独立路段含两端平地长3.2m、宽2m，网格5mm×10mm。原CAD以1mm精度三角化，采样最大高度71.024mm，中心峰距230–245mm；保留实际采样结果，不缩放到人为整齐尺寸。CAD及碰撞来源SHA见 `RMUC_ROAD_BUILD_RECEIPT.json`。

这是V2.0场地的一条独立起伏路，刚性旋转坐标将原1.5°地板坡度调平，保留凸起形状，没有复刻完整赛场，也没有核实后续V2.2 CAD相同。[官方2026 V1.2规则手册图4-36](https://bbs-web-static.robomaster.com/96d4042cd8cc4a5aad10c31c9b028e5b1767087205729/RoboMaster%202026%20%E6%9C%BA%E7%94%B2%E5%A4%A7%E5%B8%88%E8%B6%85%E7%BA%A7%E5%AF%B9%E6%8A%97%E8%B5%9B%E6%AF%94%E8%B5%9B%E8%A7%84%E5%88%99%E6%89%8B%E5%86%8CV1.2.0%EF%BC%8820251230%EF%BC%89.pdf)的70/240mm标注与此名义尺寸一致。紫色路保留原0–2.5cm练习起伏，蓝色缓坡仍为0–8cm。原场地与检查记录在 `original_mild_playground` 保存。

模型保留31个机器人body、6个闭链和4个mimic约束、8个自由导轮；从本次训练冻结import_contract恢复质量、惯量、关节限位、armature、被动阻尼及名义气弹簧参数。六动作/35维观察/PD/力矩速度限制与当前部署合同一致，无航向或扶正辅助。策略只使用actor，不输入critic特权信息。

本地MuJoCo用0.5ms Newton物理步和100Hz策略；不是远端2.5ms PhysX TGS的等价重现。试玩采用名义无噪声、无反馈和动作延迟条件，没有开启随机DR。策略本身来自D1–D5训练。旧平地和小起伏短程smoke见 `SMOKE_REVIEW.json`；新RM路的真实观察见 `RMUC_ROAD_SMOKE_REVIEW.json`：0.3m/s指令下18秒推进1.564m，尚未通过；0.5m/s指令下7.19秒发生侧向离开路面，两次均未倾倒或非有限。当前策略还没有稳定通过整条RM路，操控时可用A/D纠偏，卡住或倾倒可R复位。这些不是正式Isaac技能毕业/实车认证。原USD和MJCF项目均未覆盖，远端训练和3060评测未暂停。

权重/来源校验见 `DOWNLOAD_RECEIPT.json`；导出和场地来源见 `BUILD_RECEIPT.json`。运行数据为 `INTERACTIVE_CURRENT.json`，出错现场为 `INTERACTIVE_ERROR.txt`。
