# R36 TRAIN 航向可观测性与轮差融合可行性

[离线原始结果](<RESULT.json>)来自K=2的201–208八条**TRAIN**轨迹；0新增物理步，没有重算或覆盖原成绩。预测计算只用已记录的IMU、编码器、估计roll/pitch与公开几何；真值仅用于残差评分。

## 为什么先停下横向增益叠加

201末端真实y=+0.370279m，按估计vx/yaw积分为−0.111702m；205真实+0.359249m，推算仅+0.004865m。增加这个推算位置的闭环增益，未必减少真实误差，甚至可能方向相反。

完整D1在20×0.5ms均值**之后**施加gyro每轴±0.125rad/s均匀噪声。σ=0.125/√3≈0.07217rad/s，不再除√20。在简化gyro-only、白噪声、恒2m/s、小角度模型中，10s的积分横向误差尺度为

```text
sigma_y = v * sigma_gyro * sqrt(dt*T^3/3) ≈ 0.2635m
```

这是解释误差数量级的简化尺度，**不是所有控制架构的可靠性下界**，也不是测得的独立试次标准差。现有其他观测、闭环相关性和轮滑都会改变它。

## 轮差提供条件约束，但此版离线融合更差

公开滚动半径0.0625m。每侧用真实闭链FK/数值J和所记录q/qd/spin，先将输入gyro z置0，求两侧前向速度vL0/vR0：

```text
omega_z_encoder = (vR0 - vL0) / track
Euler_yawdot = (gyro_y*sin(estimated_roll) + omega_z*cos(estimated_roll)) / cos(estimated_pitch)
```

该关系以两轮条件纯滚动为前提，**不是独立滑移观测**；接触、轮胎有效滚动半径、编码器噪声/偏置、动态腿运动、姿态及boxcar时序差异均可能产生偏差。这里只做固定权重可行性筛查，没有逐episode拟合比例或读取DR参数。

## 范围

- 原预测使用端点q、均值qd/IMU和当前age-view姿态，存在已知通道时域差异；本离线筛查不是完整同步融合器或严密轮滑归因。
- 尚未分离各误差源的贡献，不把全部误差武断归于轮胎滑移、gyro偏置或D2。
- 未接入任何控制输出；H1/H2/H4、C3与R36结果全部保持不变。
- 下一航向改进需独立噪声/滑移约束或额外观测证据；保持车道筛选失败，不通过调整阈值包装通过率。
