# 前向ToF几何提案 V1 — 静态研究封存

**交付等级：附加传感器提案；hardware_binding=false，qualified_for_actuation=false。** 这不是已有MOD4v1传感器、已安装测距器、接触检测资格或自动跳跃控制器。原H1/H2/H4的传感器配置和成绩保持不变。

## 数据边界

- [仿真测量接口](<range_sensor_sim.py>)在独立scratch姿态中执行光线测距；对外只给距离/有效位/时间戳/序号/声明的安装信息与误差界，不暴露root位置、地形名称、contact或障碍坐标。
- [纯几何推断](<front_geometry.py>)只消费该测距包、传感器侧姿态和腿编码器、公开轮腿几何；不import MuJoCo或地图。它只能给 **ELEVATED_SURFACE_CANDIDATE**，不是“已识别台阶”，斜坡/立面也可能有相同读数。
- 唯一允许的条件推断前提是**明确声明的平坦支撑接近段**，并给定root高度/姿态/测距误差界。原接触proxy与COM研究尚未提供可信动态支撑识别，因此此条件还未由真实状态机闭合。
- 无返回、遮挡、过期、时钟顺序错误、支撑与测距偏时、姿态/几何/误差预算缺失或错误均降为UNKNOWN；任何输出的actuation资格恒false。

## 模拟规格，不是硬件规格

提议安装点chassis坐标`(.30, 0, .10)m`，向前下40°，最大量程1.5m；示例均匀噪声±5mm、100Hz一包延迟10ms。安装机械可达性、传感器/支架质量惯量、实际视场/光照/材料/多径误差、硬件时间戳、BSP、线束与电源均未绑定。没有把提议安装点变成已有机器人真实器件，也没有将质量影响加入既有plant。

仿真接口保留机器人自遮挡检查：不能穿过chassis看地面。scratch仅更新位置学，不推进物理。延迟包保留采样时刻，arrival为当前到达时刻，不伪造同步。

## 已有静态验证与失败

[attempt003原始结果](<attempts/003/RESULT.json>)：293项检查、0失败，135次静态mj_forward，**0次mj_step**。三个精确SCUT tiny_step网格高度2/4/6cm，各45个位姿点；固定名义姿态、无DR、测距噪声在此几何测试中为0。

| 几何高度 | 最大估计误差 | 候选点数量/45 |
|---|---:|---:|
| 2cm | 约13.82µm | 0 |
| 4cm | 约13.82µm | 8 |
| 6cm | 约13.82µm | 9 |

误差界测试使用声明的10mm高度、5mrad姿态预算；2cm场景在保守门限下没有候选，保留该结果，不缩减误差界换取检出。邻近静态点高度相关，这些数量不是独立检测成功率。

- [attempt001错误](<attempts/001/ERROR.txt>)：腿几何接口side误用整数导致KeyError，0物理步，原文件保留。
- [attempt002结果](<attempts/002/RESULT.json>)：修正left/right接口，292检查；安装与自遮挡语义尚非003版本，保留为前序结果而不混作同一版本重复试验。

## 证据限制与后续门槛

本封存只整理已有结果、当前源码和索引，**没有重跑这些静态测试或物理**。这组早期测试未生成执行前源码SHA收据，因此INDEX中的源码SHA是封存时字节指纹，不追认其为执行前锁定证明。

没有动态DR检测率、false-positive率、真实接近距离误差、宽度/落脚区识别、相机/雷达替代比较，也没有FSM/腿动作闭环。后续若启用，需要独立的新传感器实验分支、预先冻结噪声/时序/机械负载、与原无ToF基线并列记录，逐步验证支撑条件、停距和主动腿策略；不接入旧holdout后重写成绩。
