Default config is unbound. Explicit data/time/session declaration, valid C3 config,
init and declared math prior arm are required. Original disabled command remains
disabled and latches; explicit init+arm required to resume mathematics.
Every usable result has send_permission=0. This is not an actuation/queue API.
