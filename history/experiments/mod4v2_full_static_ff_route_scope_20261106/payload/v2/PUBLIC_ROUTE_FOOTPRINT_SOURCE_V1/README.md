- [唯一恢复脚本](<../audit_public_route_macro_heights_retry001.py>)保留原脚本，另建RETRY001，读取真实任意凸体顶点，用**现有SciPy ConvexHull**半空间作bbox候选竖线区间计算，不添加依赖、不用MuJoCo或随机抖动/假地板。源场图一字未改。
- 原失败、结构诊断、恢复各一次源XML解析；高度查询仅恢复的24次。没有额外source/archive hash，没有旧控制/电机/接触raw读取。所有大文件只在功能性源核查中读取，不为归档再读payload。
