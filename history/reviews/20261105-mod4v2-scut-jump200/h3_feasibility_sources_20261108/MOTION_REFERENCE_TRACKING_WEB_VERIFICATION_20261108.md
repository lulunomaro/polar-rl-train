# 情感示范源与鲁棒跟踪分工：本轮网页核验

日期：2026-11-08，Asia/Shanghai。只读调查；0模型下载、0训练或物理运行。

用户新增关键约束：H3生成的运动作为示范；实际操作靠训练，适应不同地形、地面、重量及外部扰动。参考实时人类示范、人形机器人跟踪的分工，不能继续强制解释为H3同时直接执行电机控制。

实际通过web.run取得正文的第一手来源：

1. https://omni.human2humanoid.com/ ，CoRL2024作者项目页。姿态作为通用控制接口；RL特权教师蒸馏可部署策略；作者展示语言运动生成器及自主agent提供运动目标，由同一跟踪策略执行。支持示范/生成目标与实际控制分工，不外推为H3已适配MOD4。
2. https://arxiv.org/html/2609.08511v1 ，PGMT，2026-09-08。摘要、IV-B及V节明确训练通用跟踪/恢复先验，加入地形观测，放宽部分跟踪误差，在需要时偏离参考而保留运动意图。复杂地形泛化不是平地随机化自动带来的保证。
3. https://supermimic.github.io/ ，作者方法和问答。世界模型与策略共同训练，策略更新时固定世界模型；梯度不穿过物理仿真器。其129514动作覆盖评估使用训练集、无DR，不能写成任意地形和未见动作泛化。
4. https://research.nvidia.com/labs/cosmos-lab/akd/ ，作者项目页。数值关节运动通过可微渲染接视频SDS梯度，随后搜索可在物理模拟实现的控制序列。支持生成先验与物理跟踪分工。重新请求 https://research.nvidia.com/labs/dir/akd/pdf/AKD_paper.pdf 返回403；没有重复下载或声称本轮PDF全文通过。
5. https://huggingface.co/DiffSynth-Studio/MiniMax-H3-NF4 ，模型卡Training Code段再次核到4090、24GB、缓存/训练分阶段、检查点和卸载配方。仅是指定SFT配置声明，未在本机验证H3动作接口。
6. https://github.com/MiniMax-AI/MiniMax-H3 ，官方说明33B主生成器，模态专用参数集中于输入/输出与AdaLN。没有提供现成MOD4动作输出及跟踪策略，需进一步适配与验证。

这是对网页的简短调查摘要，不是原始网页完整副本，不声明原件字节SHA。保存本文件的SHA由本阶段Git实验索引记录。以前的探索性结构保留在主报告，同时已明确由最新“参考生成+鲁棒跟踪”分工覆盖其必要性。
