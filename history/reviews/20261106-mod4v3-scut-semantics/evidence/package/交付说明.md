# MOD4v3 MJCF / USD 交付

基于 MOD4v2 HW300N60 独立制作，参考华南虎 V14_2 USD 和固定源码版本。

- 模型：`mjcf/scene.xml`、`assets/robot.usd`。
- OmniPhysics 有限角表达：`assets/robot_physx.usda`，引用同包 robot.usd；保留 CAD 有限止挡，未做本版 PhysX GPU 动力测试。
- 语义契约：`semantics.json`；完整逐项表：`SEMANTIC_ALIGNMENT.md`。
- 接口：`semantics.py` 的 `ScutRobotView`。它提供所有存在的对应关节标量、顺序、零位、方向与力矩变换。
- Newton 必须显式选 `position_basis='newton_displacement'`；MJCF 选 `mjcf_absolute`，USD 选 `usd_absolute`；四元数顺序也必须显式指定。
- 真实默认角度和控制配置：`runtime_config.json`；原零位并非所有 anatomical angle=0。
- MOD4 几何解算：`kinematics.py`。不能复制华南虎连杆长度或额外再加其弹簧力。
- 86 项华南虎奖励源码依赖：`SCUT_REWARD_REQUIREMENTS.json`。资产包负责状态语义，命令、射线、状态机与学习器由环境提供。

已执行：1659 项 MuJoCo/USD 检查通过；Newton1.7/SolverMuJoCo CPU 20×2.5ms 检查通过，最大闭链误差0.138331mm。14.2941402886kg、闭链、mimic、气簧300N60mm、止挡、网格、碰撞和力学参数保持。

核心对应：crank/front1、coupler/front2、rocker/front3、distal/front4、hip-thigh/rear1、knee-shin/rear2、气簧/spring1-spring2、轮轴/wheel。此前“MOD4没有rear2”的判断错误；rear2为真实膝关节。

限制：华南虎参考仓库无 MJCF，依据原 USD 和代码对齐；MOD4 少2个云台和8个华南虎导轮，逐项声明不存在且读取报错，不生成假部件。front3 原闭链树切口保留，必须通过接口取 front2 到 front3 的相对角；不能裸用 articulation 的同名 spherical joint 当标量。尝试重排成华南虎树的候选因实际编译惯量不等价已拒绝并保留原始证据。

这是一套语义与物理表示包；未启动训练、未改现有任务、未宣称奖励收敛或现有 checkpoint 通用。
