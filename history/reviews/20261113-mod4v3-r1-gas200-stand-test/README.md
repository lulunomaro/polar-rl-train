每项12秒、4800个真实物理步。三项均无非有限、闭链10mm或mimic0.01rad终止。

后收起立阶段：0.30s时机身高25.54cm、倾角12.25°；0.74s时机身高28.42cm、倾角1.07°，已向前移动约0.502m；1.00s时机身高29.03cm、倾角2.29°、水平速度约0.0034m/s。全程最大倾角18.73°。之后保持约5.45cm/s的慢速前漂。因此本次支持“能起立”，不支持“原地起立后完全静止”。正常站姿对照也存在相同量级的后段漂移。

站立判据：机身根部高度≥0.23m、倾角≤10°、双轮接地且无其它部件接地、水平速度≤0.35m/s、角速度≤0.5rad/s，连续2秒。0.74s是该连续区间的开始时刻，2.74s后才确认已经连续满足2秒。尾段2秒全部满足。
