## 实际修改

1. **补齐米、千克、Z-up元数据。** 原400N薄层独立打开时落到默认0.01m/Y-up，而其原始底层是1m/Z-up；增强版补齐声明，不缩放任何几何或关节坐标。该发现不代表既有Isaac世界场景也按厘米运行。
2. **按安装刚体修正已知电机质量。** 腿电机原0.93→厂家更正0.963kg/台，共4台；轮端原0.16假设→用户提供0.131kg/台，共2台。原厂完整396g含已拆掉的减速段，不用于当前裸机。已存在的自制15.8减速箱不重复加重。
3. **质量、质心、惯量关联更新。** 四腿电机修正归chassis，轮端修正归left_shin/right_shin。用安装关节轴锚点近似质量差的位置，通过一阶矩和平行轴公式更新COM与完整惯量，再分解为USD主惯量/主轴。锚点近似不是新CAD测得的电机COM；未知质量差的自身转动惯量未编造。
4. **独立加载的求解器默认与既选配置一致：32/4。** 配套契约物理步长从旧导入元数据0.0005补齐为当前0.0025s，配套适配器保持TGS、策略50Hz和10mm单环境闭链重置。未改为华南虎的其他时钟或降低MOD4闭链求解配置。
5. **31刚体分组与可选DR参考。** 提供按chassis/leg/wheel/spring/roller等分组的参数表与参考范围，不按每颗螺钉单独随机化。DR参考默认不启用，现有D0–D7事件不被热改。
6. **生成单层、无外部依赖的USD。** 可搬运到别的目录加载，不依赖原8.8MB底层的绝对路径。

## 两队对齐点

复旦当前JUMP的URDF为7个link/6个转动关节，加载器启用固定关节合并；其质量随机化作用在仿真刚体而不是CAD零件。所核华南虎V14 USD静态定义37个刚体/42个关节，保留自身被动机构和6个球关节闭环；转子惯量在运行资产配置中以armature表示。两队刚体数量不同，MOD4也不硬凑7体。对齐的是固定件聚合、活动件保留、质量与惯量一致性及执行/观测不确定性建模，而非复制其整车质量、求解器数字或训练配方。
