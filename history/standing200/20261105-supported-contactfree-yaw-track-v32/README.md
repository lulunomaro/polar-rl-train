# 200mm站爬 V32：站高、蹭台沿、收腿；忽略接触终止；偏航与轮距

2026-11-05人类明确：“奖励给站高，底盘蹭上台阶，收腿上台阶，导轮撞击啥的终止条件直接忽略，记得给偏航惩罚轮距惩罚”。本条覆盖V31仅对已验证台顶支撑免接触终止的限制，也覆盖必须前进才能得到站高奖励的设计。V31原源码、FROZEN、检查与失败保留；V32只新增小型delta，引用V31原字节，不复制运行框架。

- 站高奖励使用实际机身高度与轮子落地/实际支撑，不再要求正向速度。台下目标0.39m，底盘实际支撑后0.42m，双轮上台后0.50m；初始悬空的高位置不给站高信用。
- 底盘实际接触到200mm台沿上部或台顶时给蹭台沿奖励；在实际台顶支撑后按真实轮缘抬升给收腿奖励。台沿触碰和挂台本身不算技能成功。
- 底盘与全部8个导轮的撞击/接触终止一律关闭，不要求先站直、达到高度或先取得台顶法向力；接触测量仅用于奖励和回放。底盘/导轮接触不收undesired-contact罚分，其它结构接触只保留原成本。
- 保留原倾倒、非有限数值/观测、闭链0.01m、mimic0.01rad与时间上限。偏航通过独立负奖励约束，不新增偏航终止。
- 偏航偏离台阶法向有连续平方惩罚。轮距使用偏航对齐坐标里的左右轮心横向有符号间距，参考增强契约0.4376m，容差0.02m；另惩罚前后错轮，代替旧no_fork重复项。抬轮造成的高度差不计入轮距，不惩罚必要的上下台过程。

仍为本地未部署候选。先完成已有V30终末回传和实际轨迹审查，再验证冻结SDK/完整恢复接入，使用原canonical与锁按完整保存边界推进。不能把CPU通过称为原生训练或200mm技能通过；任何已运行任务不热改。
