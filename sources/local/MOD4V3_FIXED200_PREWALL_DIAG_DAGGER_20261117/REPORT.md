# 平地起步根因检查：第一阶段实测报告

日期：2026-11-17（北京时间）。本阶段 **PPO 更新 0 次**。仅对独立 actor 副本做了 **64 次 Adam 离线小批次拟合探测**，耗时 0.390 秒；随后独立回放失败，未采用。不是新一轮远端 PPO，未续训或晋升模型。

现在最先坏的是 stair 模式下的平地起步闭环：两个 repair 检查点、全部五起点都在真实触阶前大幅收腿掉高。原教师多数情况下能从这些状态救回来；但补数据后的简单离线拟合仍未形成稳定学生。采样修正方向合理，不能把“67% 技能样本让它误判撞墙”写成已经证明的唯一原因。

## 3. 35维可分性与动作标签冲突

归一化：原8391帧 + 新合格1838帧平地观测，共同估计每维均值/标准差；标准差<.001的维度按常量处理。报告归一化35维RMS距离和有效维数敏感性，不把某一阈值当作可观测性的定理。跨类为新平地idle与原 contact_pre_lift/lift（985帧）；原cruise（776帧）作参照。

- 重点低轮速133帧，按小数6位去重后72种观测；到原触阶/lift的最近邻RMS距离 min **0.1646**、median **0.3278**。**133/133都更接近原巡航而非触阶/lift。**
- 这133个跨类最近邻对，在双方动作均超过0.15死区的定义下，轮动作均值／rear动作均值的反号冲突均为 **0/133**。其中距离≤.25的21对也是0。
- 同时按原PD公式反算、尚未经电机包络截断的轮矩请求，有 **83/133** 最近邻对方向相反；≤.25的21对均有此现象。它们的完整观测并不相同，阻尼项也不同，因此不能直接说成“相同输入必须给相反标签”。rear PD方向冲突0/133。完整配对与动作差异保存在SEPARABILITY.json。
- 全部1838帧平地idle中，1546个最近邻距离≤.25，其稳健轮/腿动作反号冲突均为0；有43个轮PD请求方向不同。

原池里也不是完全没有“0.47指令＋低轮速”：旧8391帧按同一低轮速条件已有468帧，其中巡航50帧、触阶94帧、lift4帧、capture319帧、post1帧。旧接管规则确实没有针对当前repair的触墙前偏离补纠偏，但不能把它泛化成所有此类观测都为空。

结论：有新状态覆盖缺口，但本次体检没有找到必须新增观测维度或已证明的强标签不可分证据。暂不能从“输入没有显式接触位”推导出35维不可用。
