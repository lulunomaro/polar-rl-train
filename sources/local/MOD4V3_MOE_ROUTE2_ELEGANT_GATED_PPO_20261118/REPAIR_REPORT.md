# MOD4V3_MOE_ROUTE2_ELEGANT_GATED_PPO_20261118 修复说明

## 1. 为什么上一轮 `LOWSPEED_PARK_REPAIR` 的 10m 检查点出现深蹲与左右抽搐

人类审看 `MOD4V3_MOE_ROUTE2_LOWSPEED_PARK_REPAIR_20261118` 10 分钟检查点视频后准确指出：**机器人在平地助跑阶段没有站高直走，而是塌腰深蹲并伴随严重左右乱跳抽搐**。

经闭环轨迹拆解与梯度冲突量化，锁定两项结构性根因：
1. **无门控单网络梯度冲突（`cos = -0.718`）**：原 `v1`（`a55eeaed`）试图用同一个无门控 MLP 在几乎相同的 35 维局部观测下同时输出**高姿平地行走（`a_leg = [+0.52, -0.15]`）**与**触墙收腿提轮（`a_leg = [+1.44, +3.30]`）**，导致第 `1.0~1.5s` 给前进指令瞬间输出折中深蹲动作，机身高度直接塌至 `0.18m` 擦地。
2. **6 自由度非对称探索叠加深蹲擦地产生剧烈抽搐**：无门控 `E1` 在深蹲擦地状态下做独立左右轮/腿 PPO 探索（`|da|_leg = 0.125`，左右轮差 `0.61`），演化为左右劈叉抽搐。

因此已按安全规程通过 `REQUEST_STOP` 提前安全停掉 `MOD4V3_MOE_ROUTE2_LOWSPEED_PARK_REPAIR_20261118`（`1561.902s`，`158 PPO / 1896 Adam`，`SAFE_CLOSED.json` 已落盘，GPU 释放，完整保留于原目录）。

## 2. 本轮核心架构与训练修复（纯观测 `35 + 420 -> 6`，零运行时教师/零特权输入）

在完全保留 `Route-2` 双专家硬隔离（`E0` 100% 锁定 `c874` 零梯度、零参数变化）的前提下，重构 `E1`（`StairExpert`）为**接触门控 + 台顶驻车双头纯神经网络结构**：

1. **冻结高姿直走基座 `approach_base` + 冻结纯历史接触门控 `gate`**：
   - 平地助跑阶段由冻结高姿行走网络输出笔直、高姿（`z ≈ 0.405m`）、零抽搐对称步态，彻底根除平地深蹲与抽搐。
   - 纯 `12×35` 观测历史门控 `gate` 仅在轮子接触 `20cm` 台阶立面产生真实减速/接触特征时平滑拉起，切换到可训练攀爬头 `head`（`51 -> 256 -> 128 -> 64 -> 6`）。全程无任何世界坐标 `x`、无接触力传感器特权输入、无 FSM 时钟。
2. **独立可训练台顶驻车头 `top_head`（解决台顶倒车掉台）**：
   - 双轮上台切低姿指令（`obs[3] < 1.5`，即 `h_cmd = 0.20m`）后路由至专门经 LQR 台顶制动与闭环 DAgger 预热的 `top_head`，实现上台后平顺降姿至 `0.20m` 并在 `v_cmd = 0` 下稳稳刹停驻车（实测末端速度 `|vx| < 0.01 m/s`）。
3. **显式左右对称正则 + 物理潜变量锚定 + 低噪声微调**：
   - `route2_optimizer.py` 加入直线攀爬/驻车双侧腿与双侧轮对称损失 `(a_L - a_R)^2`、前 5 维物理历史编码锚定及平滑动作锚定；
   - `fixed200_reward_math.py` 增加双轮动作对称项；
   - `E1` 初始探索标准差收紧至 `[0.012, 0.012, 0.012, 0.012, 0.025, 0.025]`，杜绝 PPO 破坏平滑步态；
   - `bootstrap_replay/elegant_r2_clean` 彻底剔除旧 `v1` 深蹲轨迹，仅装入新 `model_step000.pt` 实测 `<= 0.60 m/s` 的优雅上阶+台顶驻车轨迹。
