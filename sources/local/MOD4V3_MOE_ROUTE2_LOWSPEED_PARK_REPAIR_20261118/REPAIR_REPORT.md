# MOD4v3 低速助跑 + 台顶停车（v=0, h=0.20m）+ 四阶段隔离回放修复报告

## 1. 视频与闭环逐帧诊断发现的四大根因

通过对上一轮 `model_final` 与补测高光点 `model_025m`（`4/5` 双轮登顶、`3/5` 台顶稳态 >=0.4s）的 MuJoCo 视频及轨迹逐帧审查，锁定此前纯 E1 正式 `<=0.6 m/s` 始终 `0/5` 的四个物理与代码根因：

1. **台顶停车状态失配（最致命根因，导致即便 <=0.6 m/s 登顶也必掉台）**：
   - 独立正式评测 `evaluate_student200.py` 全程跑满 `10.0s`（500步）：当台顶连续稳态满 `0.4s` 时触发 `stop = True`，将速度指令切换为 `v = 0.0 m/s`、身高指令为 `h = 0.20 m`（`obs[0]=0, obs[3]=1.0`），并要求在 `10.0s` 结束时仍保持双轮台顶稳态。
   - 然而原 `v1`（`a55eeaed`）在 `(v=0.0, h=0.20m)` 输入下输出轮动作 `[-0.175, -0.441]`，实测会以 **`vx = -0.95 m/s` 全速倒车并在 `1.0s` 内倒掉下台阶**。
   - 旧训练代码一方面在满 `0.4s` 时立即 `timeout` 重置环境，使学生从未在训练中见过台顶 `(v=0.0, h=0.20m)` 停车状态；另一方面 `route2_optimizer.py` 对所有 `|obs[0]| < 0.05` 施加永久 `8.0` 的 `v1` 锚定，一旦进入台顶零速状态反而强迫学生模仿 `v1` 倒车掉台。

2. **`settle_anchor` 时窗错位（强迫复刻 `v1` 的 `1.03 m/s` 平地猛冲）**：
   - 环境在 `t = 1.0s`（`SPEC.settle_seconds = 1.0`）即发出 `v_cmd = 0.47 m/s`，而原 `v1` 在 `1.0~1.5s` 会猛蹿至 `1.026 m/s`。
   - 旧 `route2_train.py` 将 `settle_anchor` 设为 `age < 1.5s`（系数 `8.0`），在 `1.0~1.5s` 强迫策略复刻 `v1` 的 `>1.0 m/s` 猛冲，直接踩爆正式评测“整程峰值速度 <=0.6 m/s”红线。

3. **单队列 FIFO 回放挤出静站桶 + 高速冲刺轨迹污染**：
   - 旧 `SuccessReplayPool` 共用单 `32,768` 帧 FIFO，在线轨迹剔除起步帧后在 `25~30m` 将原 `v1` 的 `150` 帧静站样本全部挤出（`settle: 150 -> 0`），空桶退回冲刺/爬台样本抽样，导致开局静站退化至 `-9.67 cm`、每 5 分钟新增成功从 `+28` 暴跌至 `+3 / +1`。
   - 同时旧种子混入了 `04c0211c` 冲刺轨迹，在线未限制入池峰值速度，BC 损失持续强化 `>1.0 m/s` 助跑与平地深蹲（`z = 0.18m`）。

4. **平地助跑缺乏 `0.54~1.2 m/s` 温和限速与抗深蹲约束，且爬墙瞬时俯仰峰过严**：
   - 首档 `speed_limits = 1.5 m/s` 对 `1.1 m/s` 助跑零惩罚，`height` 系数 `0.05` 对平地深蹲至 `0.18m` 仅罚 `0.001/step`；而爬 20cm 竖直立面时瞬时俯仰超过 `25°` 即整回合永久剥夺台顶奖励（正式评测仅要求登顶后 `<25°`、全程不触发 `>40°` 0.2s 终止）。

## 2. 本轮独立修复内容（仅限本目录 `MOD4V3_MOE_ROUTE2_LOWSPEED_PARK_REPAIR_20261118`）

- **台顶停车闭环对齐**：`continuous_stair_env.py` 在台顶移动稳态满 `0.40s` 后触发 `course_stop_latched = True`（发一次性里程碑奖 `+6/+10`），将速度指令切为 `0.0 m/s`（`h = 0.20m`），要求继续在台顶完成 **`1.00s`（50步，超 4 倍历史窗）速度 `<=0.20 m/s` 的平稳驻车** 才计 `course_success` 并结束回合。
- **精准锚定作用域**：永久 `8.0` 的 `v1` 静站锚仅作用于 `t < 1.0s` 且 `v_cmd == 0, h_cmd > 0.34m` 的高姿起步静站；台顶 `(v_cmd == 0, h_cmd = 0.20m)` 处 `v1` 锚系数严格置 `0.0`；移动段 `high_anchor` 降至 `0.60 -> 0.10`。
- **四阶段独立回放池（永不淘汰 `v1` 静站）+ 低速种子精选**：
  - `phase 0 (settle_high)` 永久锁死原装 `v1` 的 `150` 帧静站样本（绝不 FIFO 淘汰）；`phase 1 (approach)`、`phase 2 (top_climb)`、`phase 3 (top_park)` 各自独立环形缓冲。
  - 剔除全部 `04c0211c` 冲刺轨迹，仅用冻结 `v1` 静站/低速回合 + 上轮实测筛选的 `8` 条低速低俯仰（`<=0.71 m/s, <=21.3°`）原生学生成功回合（共 `5,444` 帧）冷启动；在线入池门槛设为 `<=0.78 m/s`，攒满 8 条严格低速后自动收紧至 `<=0.60 m/s`。
- **温和低速塑形与抗深蹲**：新增 `moving` 段 `speed > 0.54 m/s` 二次方软限速惩罚，提高 `height_aux` 至 `0.30` 抑制助跑深蹲，台顶驻留奖在整程峰值 `<=0.60 m/s` 时享 `1.25x` 质量加成，爬墙历史俯仰峰容许至 `38°`（台顶瞬时仍严格 `<25°`）。
- **硬边界零改动**：父权重锁定原 `v1/a55eeaed`，`E0`（`c874`）完全冻结，物理步长/TGS32-4/电机/PD/35+420输入/78critic/6动作/0DR→5起点→渐进fullDR课程及默认模型指针完全不变。
