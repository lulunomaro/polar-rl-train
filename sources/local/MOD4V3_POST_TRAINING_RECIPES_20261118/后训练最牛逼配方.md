## 三、 配方一：纯神经网络 RL 轮腿优雅上台阶与台顶零速驻车（`5/5` 满分毕业配方）

> 对应源码目录：`sources/local/MOD4V3_RL_SINGLE200_FULLDR_5OF5_20261118`（单阶 `5/5` 毕业 + `Full-DR`）与 `sources/local/MOD4V3_MOE_ROUTE2_CONTINUOUS_2STEP_ANTICHEAT_20261118`（连续二级 `20+20=40 cm` 扩展）。

### 1. 五大历史踩坑根因与决定性解法（必读，少踩一周坑！）

1. **平地塌腰深蹲擦地与左右抽搐根因（梯度反相冲突 $\cos = -0.718$）**：
   - **现象**：用单个无门控 MLP 同时训练“平地高姿直走 (`0.409 m`)”与“触阶极度缩腿 (`0.175 m`)”，由于触墙前 1 帧与触墙后 1 帧状态极近但目标动作完全相反，网络退化为折中深蹲（`0.18 m`）蹭地左右抽搐。
   - **根治方案**：在 `StairExpert` 内部采用 **冻结高姿直走头 `approach_base(35->6)` + 纯历史接触门控 `gate(420->128->32->1)` + 可训练攀爬头 `head(51->6)`**。平地未触墙时 `gate_prob < 0.004`，`100%` 输出笔直平稳的 `approach_base`（实测上千回合首秒塌腿率 **`0.00%`**）；导轮/轮胎触碰台阶立面瞬间 `gate_prob -> 1.0`，无缝切入 `head` 双腿同步缩腿上台。
2. **蹭阶滑落刷分作弊（Touch-and-Slide Reward Hacking）**：
   - **现象**：只给台顶接触密集奖励而不追回，策略会蹭一下台面拿分再滑下台阶反复刷分。
   - **根治方案**：**零容忍掉阶终止**——一旦双轮越边（`landed = True`）或单轮在阶顶累计支撑 $\ge 6$ 帧后，若任一车轮高度跌破 `step_height + R_w - 0.035 m` 或机身退回 `x < step_edge - 0.05 m`，**立即扣除 `-25.0` 分并当场终止回合 (`done = True`)**；且单轮触顶但 `vx < 0.05 m/s` 时密集奖励严格为 `0`。
3. **`env.step` 自动重置清零导致超速轨迹污染回放池**：
   - **现象**：Isaac Lab 在 `timeout/done` 时先执行 `_reset_idx` 把 `episode_max_speed` 清零，随后回放记录器读到 `0.0 m/s`，导致 `0.9 ~ 1.3 m/s` 猛冲轨迹混入 BC 池，20 分钟后策略因超速（`> 0.60 m/s`）掉回 `0/5`。
   - **根治方案**：必须在 `_reset_idx` 之前锁存真实回合峰速 `replay_episode_max_speed_at_step`，在线新轨迹严格满足 **`max_speed <= 0.58 ~ 0.60 m/s`** 且末端 `|vx| <= 0.035 m/s` 方可进入回放池。
4. **`1.0 s` 提前重置导致台顶慢速倒溜掉阶**：
   - **现象**：若训练环境在台顶驻车满 `1.0 s`（`|vx| <= 0.20 m/s`）就提前结束回合，策略会容忍 `vx = -0.12 m/s` 的微小后溜偏置；到了 `10.0 s` 不提前重置的实测中，`-0.12 m/s × 4 s = -0.48 m` 直接从台阶后沿滑落！
   - **根治方案**：必须在 **完整 `500` 步（`10.0 s`，零提前成功重置！）** 回合上训练 `top_head`，分两段引导：
     - **越边拉进段**（刚上台前 `0.40 s`，`obs[3] = 1.0, v_cmd = 0.47`）：奖励 `vx ≈ +0.34 m/s`，把车身向台内拉进 `25 ~ 50 cm` 远离悬崖边；
     - **死锁驻车段**（`stop = True`，`obs[3] = 1.0, v_cmd = 0.0` 直至 `10.0 s`）：高窄高斯零速奖 `+0.55 * exp(-(vx/0.035)^2) - 3.5 * |vx|` 叠加**非对称反倒溜重罚 `-10.0 * relu(-vx - 0.01)`**，实现 `|vx_final| < 0.009 m/s` 纹丝不动！
5. **编码器隐空间后 11 维被清零屏蔽 & Adam 首步符号跳变破坏多起点盆地**：
   - **根治方案**：保留 `HistoryFeatures (420 -> 128 -> 64 -> 16)` 全部 `16` 维时序特征输入 `head` 与 `top_head`（切勿将 `head[0].weight[:, 40:51]` 置零！），使网络能感知五起点（`-60..+60 mm`）助跑到达台阶时的微小俯仰振荡相位差；在 PPO 收敛至 `4/5 ~ 5/5` 越边盆地后，使用 **末层闭环无梯度 CEM + 微半径极值精调** 直接优化非光滑 `max_t ||v(t)|| <= 0.60 m/s` 指标，避开 Adam 冷启动 `sign(grad)` 跳变。

### 2. 四步标准训练流水线与超参数

1. **Step 1 — 准备五起点干净低速种子回放**：
   收集覆盖 `-60 / -30 / 0 / +30 / +60 mm` 五起点一次直上、零反弹、整程峰速 `<= 0.55 m/s` 的纯学生轨迹（`bootstrap_replay/elegant_r2_clean/*.npz`）+ `150` 帧永久锁死高姿静站帧（权重 `8.0` 不淘汰）。
2. **Step 2 — 远端 Isaac Sim 单阶反作弊预训（可选加速，40 分钟内取 `25m` 最优稳态驻车点）**：
   `819/819` 台阶环境 `100%` 设为单级台阶，前 `15` 轮 Critic-Only 预热，低探索 `STD = [0.008, 0.008, 0.008, 0.008, 0.018, 0.018]`，获取具备 `4.90 s` 台顶稳停能力的检查点（`model_025m.pt`）。
3. **Step 3 — 目标 `400 Hz` MuJoCo 全长闭环 Active-Mask 渐进 DR PPO（`stage2_ppo_fulldr_train.py`）**：
   - **Active-Mask 机制**：仅在 `(obs[:, 3] < 1.5) | (gate_prob(hist) > 0.04)` 激活步计算 PPO Surrogate、`approx_kl` 与全幅探索噪声（平地接近段仅加 `0.12x` 微抖动泛化到阶相位），梯度信噪比提升 `10` 倍；
   - **超参数**：`ValueNet(78 -> 256 -> 128 -> 64 -> 1)` 前 `6` 轮 Critic 独立预热（`lr = 3e-4`）；随后 `30` 轮 Actor 更新（`lr = 1.2e-5`，`clip = 0.16`，`kl_stop = 0.020`，双侧对称损失 `0.20 * loss_sym`，干净回放锚定 `0.38 * loss_rep`）；
   - **渐进 DR 课程**：按 `dr_scale = 0.00 -> 0.25 -> 0.50 -> 0.75 -> 1.00` 逐级注入质量 `±12%`、质心 `±2.0 cm`、轮地/阶面摩擦 `[0.65, 1.25]x`、PD 增益 `±12%`、电机力矩上限 `±10%`、阶高 `±5 mm`、观测噪声与 `0..20 ms` 动作延迟（每轮保留 `33%` `0-DR` 锚定回合防止名义退化）。
4. **Step 4 — 末层闭环 CEM 与微半径锁 `5/5` 精调（`stage3_es_5of5_fulldr.py` -> `lock_5of5_exact.py`）**：

## 四、 配方二：平机身低俯仰 (`<= 8.70°`) COD 前向跳扑与直跳 `16/20/24 cm` 高台纯 RL 配方

> 对应源码目录：`sources/local/MOD4V3_RL_FORWARD_LEAP_STEP_JUMP_20261118`。

### 1. 核心物理原理：彻底解耦“虚拟腿摆角 $\bar{q}$”与“机身俯仰角 $\theta_{\text{pitch}}$”

为什么普通大跳策略要么**原地竖直跳/落地倒退**，要么为了往前扑出现 **`28.85°` 夸张抬头/栽头俯仰**？  
因为混淆了车体俯仰角 $\theta_{\text{pitch}}$ 与独立前后髋合成的虚拟腿运动学：
- **虚拟腿伸长量**：$\delta = q_{\text{front}} - q_{\text{rear}}$（决定机身高度与起跳竖直蹬伸冲量）；
- **虚拟腿前后摆角**：$\bar{q} = \frac{1}{2}(q_{\text{front}} + q_{\text{rear}})$（决定车轮相对水平机身的前后落点：`+\bar{q}` 车轮后掠，`-\bar{q}` 车轮前伸）。

**黄金法则：前向起跳助推与空中 Raibert 落足前伸 `100%` 由虚拟腿摆角 $\bar{q}$ 与车轮速度承担，机身目标俯仰角 $\theta_{\text{pitch,ref}}$ 全程锁死为 $0^\circ$！**

#### 四阶段平机身控制内化细节（用于生成零擦碰低俯仰 Stage-1 DAgger 演示源）：
1. **`CROUCH`（低姿平机身蓄力加速，静止 `0.64 s` / 移动 `0.44 s`）**：
   - 严禁高姿猛加速（高质心切向力矩 $-F_x z_{\text{com}}$ 会直接把车头掀翻翘起！）；
   - 先延迟 `0.08 ~ 0.15 s` 柔和下潜至安全深蹲角 `ct = 0.495 ~ 0.515 rad`（确保前导轮 `0.0 N` 零擦地），在低重心下通过车轮加速 $v_{\text{lunge}} = \max(v_{\text{cmd}}, 1.92 - 0.22\min(0.85, v_{\text{cmd}}))$ 与微小腿后掠 $\Delta\bar{q} = +0.020 v_{\text{lunge}}$ 建立起跳前向速度 **`vx_takeoff = 1.20 ~ 1.43 m/s`**，此时机身俯仰自然稳定在 **`<= 5°~6°`**。
2. **`PUSH`（等速跟随 + 零净俯仰冲量满幅蹬伸）**：
   - 双腿全行程快速伸展的同时，车轮切为**等速跟随 `0.94 * body_vx`**（切断地面切向加减速翻转力矩），并注入精确配平的前后髋偏置：
     $$\Delta\bar{q}_{\text{push}} = -0.326 + 0.085\max(0.95, v_{x,\text{push}})$$
     使离地瞬间机身俯仰角速度 $|\omega_{y,\text{takeoff}}| \approx 0\text{ rad/s}$，从源头消灭空中翻转角动量！
3. **`FLIGHT_TUCK -> LANDING_EXTEND`（腾空锁平 `pitch_ref = 0` + 双轮对称动量轮阻尼）**：
   - 离地瞬间快速收腿至 `delta = 0.173 rad`（赚取 `30.4 ~ 32.0 cm` 世界轮底净空以飞越 `16 / 20 / 24 cm` 台阶立面）；
   - 前伸落足仅作用于虚拟腿摆角：$r_{\text{air}} = \text{MEAN\_GRID}(\bar{\delta}) - 0.55\theta_{\text{pitch}} + 0.16 v_x$；
   - **双轮对称动量轮 + 四连杆同相俯仰阻尼**（利用左右轮平均转速 $\bar{\dot{q}}_w$ 防止航向偏斜）：
     $$m_t = 0.5(15.5\theta_{\text{pitch}} + 1.40\omega_y), \quad a_{4:6} = \frac{\bar{\dot{q}}_w + m_t / 0.6}{10.0}, \quad \Delta a_{0:4} = 2.0\,\text{clip}(3.5\theta_{\text{pitch}} + 0.28\omega_y, -0.48, 0.48)$$
     将腾空最大机身俯仰死死锁在 **`<= 8.70°`**！
4. **`SKYHOOK_ABSORB -> CRUISE_HOLD`（`1.90 s` 门控平滑缓降 + 高台提前触地自适应吸能）**：
   - 倒立摆若在 `0.4 s` 内从 `1.2 m/s` 急刹至 `0`，物理上必然产生 $\arctan(a_x/g) \approx 17^\circ$ 抬头角；因此将 `obs[30] = 1` 门控窗口设为 **`1.90 s`（`95` 拍）**，触地后用 `1.05 s` 平滑缓降（物理倾角 `< 6.5°`）；
   - 施加**接地态反翘头髋阻尼** $\Delta\bar{q}_{\text{skyhook}} = (1 - t_{\text{absorb}}/0.30)(0.95\min(0, \theta_{\text{pitch}}) + 0.05\min(0, \omega_y))$，把 `24 cm` 高台落台瞬态俯仰压至 **`<= 10.82°`**！

### 2. 纯神经网络结构与三维高台环境建模要点

- **网络结构 (`moe_forward_leap_model.py`)**：
  - `obs[30] <= 0.5`：输出冻结 `E0 (c874)`；
  - `obs[30] > 0.5`：`PureNeuralForwardLeapExpert` = 冻结 `loco_base(35->6)` + `TemporalHistoryEncoder`（双层 `Conv1d(35->64->64, stride=2)` 提局部冲击微分特征 + `LayerNorm MLP(804->256->128->64)`）+ 残差头 `delta_head(99->256->256->128->6)`。
  - **为什么零特权输入就能适应平地与 `16/20/24 cm` 不同高度台阶？** 因为当车轮提前 `80~140 ms` 落上高台平面时，`obs[16:22]`（腿/轮关节角速度）与 `obs[4:7]`（陀螺仪）产生鲜明的接触冲击特征，`Conv1d` 历史编码器在 `1` 拍（`20 ms`）内即可自动切入缓冲吸能与台顶稳停/巡航！
