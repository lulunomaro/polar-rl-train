## 2. 三大物理根因拆解与平机身摆腿控制律修复

1. **根因一：高姿蹬伸期车轮猛加速引发“翘头角动量 (`L_total < 0`)”**
   - 原版在 `PUSH` 伸腿至 `0.40 m` 高姿时继续对车轮施加强加速 (`n_obs[0] = 1.69`)，地面前向切向力 $F_x$ 对升高质心产生巨大抬头力矩 $-F_x \cdot z_{\text{com}}$，离地瞬间俯仰角速度 $|w_y| > 1.5\text{ rad/s}$。
   - **修复**：在低重心蓄力期 (`CROUCH`, `0.64s` 静止 / `0.44s` 移动，机身 `|pitch| <= 5°`) 提前建立前向速度 `vx_takeoff = 1.20 ~ 1.43 m/s`，并在爆发蹬伸期 (`PUSH`) 精确配平车轮等速跟随 (`0.94 * vx`) 与前后髋力矩偏置 (`mean += -0.326 + 0.085 * vx`)，使离地角动量处于全局抛物线极小点，腾空峰值俯仰压至 **`8.04° ~ 8.70°`**。
2. **根因二：腾空非零俯仰目标与落足摆角耦合机身倾角**
   - **修复**：腾空期 (`FLIGHT_TUCK` & `LANDING_EXTEND`) 严格锁定机身目标俯仰 **`pitch_ref = 0.0 rad`**，采用双轮对称角速度动量轮反作用控制 (`mt = 0.5 * (15.5 * pitch + 1.40 * wy)`) + 四连杆同相姿态配平；Raibert 前伸落足完全由虚拟腿相对水平机身的髋摆角 $r_{\text{air}} = \text{MEAN\_GRID}(\bar{\delta}) - 0.55\theta_{\text{pitch}} + 0.16 v_x$ 承担，机身保持水平飞越 `16/20/24 cm` 台阶前沿。
3. **根因三：触地后倒立摆急刹抬头 (`atan(a_x / g)`) 与接地后仰力矩**
   - **修复**：将 `JUMP_GATE_DURATION_S` 扩展至 `1.90 s`（`1.05 s` 平滑巡航缓降，减速度压低至 `~1.0 m/s²`），并加入接地态反翘头髋部阻尼 (`+0.95 * min(0, pitch) + 0.05 * min(0, wy)`) 与 Stage-2 PPO 全局刚性低俯仰密集奖惩：
     $$r_{\text{pitch}} = +0.40\exp\!\left(-(\theta/0.08)^2\right) - 0.15|\omega_y| - 8.0\,\text{relu}(|\theta|-8^\circ) - 25.0\,\text{relu}(|\theta|-12^\circ)$$
     使触地缓冲与台顶驻车全过程最大俯仰严格受控在 **`8.04° ~ 10.82°`**。
