## 2. 网络架构与两阶段 RL 训练结果 (`BC+DAgger -> Anti-Cheat PPO`)

### 2.1 MoE 纯本体感受网络 (`moe_jump_model.py`)
- **`E0` (`obs[30] <= 0.5`)**：原封不动冻结 `c874` `ActorMLP (35 -> 256 -> 128 -> 64 -> 6)`。
- **`E_jump` (`obs[30] > 0.5`)**：`PureNeuralJumpExpert`：
  - `TemporalHistoryEncoder`：对 `12 × 35` 本体历史窗口执行归一化 + 双层 `Conv1d(35->64->64)` 多尺度时序特征提取 + 全局拼接 `LayerNorm MLP` -> `64D` 潜变量；
  - 残差动作头：`loco_base(normal_obs)`（冻结 `c874` 支路） + `delta_head([obs_norm(35), z_hist(64)] -> 256 -> 256 -> 128 -> 6)`；
  - 全部五阶段动态时序（`CROUCH 深蹲蓄力 -> PUSH 满行程爆发蹬伸 -> FLIGHT_TUCK 空中快收腿 -> LANDING_EXTEND 等速 Raibert 落足 -> SKYHOOK_ABSORB 天棚柔顺缓冲`）完全由网络根据 `obs[30]` 上升沿及关节角/角速度/历史动作本体感受内生涌现。
- **`JumpValueCritic`（仅训练期使用）**：非对称价值网络 `obs(35) + hist(420) + priv(14) -> 1`，推理/部署期零依赖。

### 2.2 Stage 1：多工况闭环 DAgger 热启动 (`stage1_bc_dagger.py`)
- 采集 `330` 回合（`26,568` 帧高动态跳跃样本，覆盖 `vx_cmd ∈ [-0.6, +1.25] m/s`、单跳、连续三连跳、`14~20 cm` 实体跨栏及物理随机化）：
  - `Round 0 (beta=1.0)`：`150/150` 存活，`145/150` 零擦地，均值净空 `33.91 cm`；
  - `Round 1 (beta=0.25)`：75% 纯学生闭环驱动纠偏，`90/90` 存活；
  - `Round 2 (beta=0.00)`：**100% 纯学生闭环驱动**，`90/90` 存活，产出热启动权重 `weights/model_bc_dagger.pt` (`SHA256 = 0ffcfad041b9...`，初始验证综合分 `163.64`)。

### 2.3 Stage 2：闭环反作弊渐进 DR PPO 微调 (`ppo_jump_train.py`)
- 在 14 路并行 MuJoCo 环境中完成 `36` 轮（`129,024` 闭环策略步 = `1,032,192` 个 `400 Hz` 物理子步）强化微调：
  1. **前 8 轮 Critic-Only Warmup**：对齐随机探索分布并独立预热非对称 Critic (`vf_loss: 1.00 -> 0.60`)，消除冷启动冲击；
  2. **反作弊奖励设计**：仅在双轮竖直无擦地落定后发放峰值离地净空大奖 (`+9.5 * clr_score^1.2`)，并在跳跃窗口结束未达 `22 cm` 净空时施加 `-8.0` 拒跳反作弊重罚，配合双侧镜像对称损失 (`0.35 * symmetry_loss`) 与干净轨迹锚定；
  3. **精确步长信任域校准**：采用低方差探索 `STD = [0.020..0.030]` 搭配 `Adam lr = 6.0e-6` 与仅在 `obs[30] > 0.5` 掩码步计算的 `target_kl = 0.012`，实测全程 `approx_kl = 0.0065 ~ 0.0093` 平滑无震荡；
  4. **渐进 DR 课程 (`0-DR -> 50% DR -> 100% Full-DR`)**：第 20 轮取得最高双域综合分 **`167.90`** (`0-DR 100% 存活 / 100% 零擦地 / 33.69 cm`，`Full-DR` 存活率由 `78.6%` 提升至 `85.7%`、净空升至 `29.75~29.94 cm`)，保存最优检查点 `weights/model_rl_best.pt` (`SHA256 = 9bad1458faaf...`) 与末轮检查点 `weights/model_rl_final.pt` (`SHA256 = 2229522debe5...`)。
