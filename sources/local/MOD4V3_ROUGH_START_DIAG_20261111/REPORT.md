# R1 坡面起步、轮胎摩擦与速度误差排查归档

日期：2026-11-11。本档案记录两组固定权重配对回放及本机 MuJoCo 打开记录；没有训练、没有更改训练配方、没有更新模型；只在独立评测中逐项恢复DR参数。

## 结论与边界

1. 原0.5–3s速度窗口包含坡面零速起步、碰阶、爬升和重新加速。它不是稳态误差；正常动力学耗时与坡向重力不能直接归为策略退化。
2. 在本次相同初态和其他随机参数下，轮胎接触摩擦是中级正阶坡面起步出现额外欠速/倒滑的主要被测因素。仅恢复轮胎静/动摩擦到0.9，就把Flat平均速度−0.2055提高为+0.4627m/s，R1三次005m从−0.0609提高为+0.7426m/s。
3. 只恢复轮胎恢复系数、导轮摩擦或机身摩擦没有同量级改善；单独恢复COM、质量、增益/effort、关节摩擦也未消除该段问题。去噪声/延迟有小幅改善，不能说完全无影响。
4. 以上证明的是这个起步/地形/权重条件下的参数敏感性，不能据此认定全部欠速都正常、DR实现有错、低摩擦必然不可通过、或者训练一定能解决。并未对所有技能和地形作根因证明。
5. 建议继续R1并保留原−1.5e²速度平方项，不再根据这一混合窗口继续增加平方/三次权重。完整DR保留，实际改进以同条件行为对照判断。

## 配对实验口径

每组使用Flat1.5_020m与R1三次项005m两份固定PT；8类非平地×正反1m/s×10初态×9条件×2模型，共2880环境，每条5s。两组总5760条5s流。seed66，R1 level3。
统计只取首次episode的0.5–3s重置前状态。速度v=body_vx*cos(pitch)，e=v−command。窗口早于5.5s外力和6s速度push，因此这里的fullDR表示完整DR配置下的扰动前段，不宣称样本已受到所有区间事件。

保留MOD4资产、电机包络、35/78/6接口、2.5ms物理/10msPD/20ms策略、TGS32/4、2mm单env闭链重置。两组numerical均0、动作槽误差0、六电机包络超出0；均有SAFE_CLOSED成功标记。单env其它真实终止/timeout仍保存在RESULT中，不因numerical0改为全部通过。

## 倒滑/打滑证据

R1三次005m在完整DR上，两轮平均角速度约+9.58/+9.68rad/s，轮心世界x速度约−0.156/−0.136m/s；只恢复轮胎摩擦后，轮心x速度约+0.746/+0.759m/s。轮向前转但轮心后退的样本比例从28.57%降到0.91%（按两轮时刻统计），机身速度为负的时刻从55.40%降到2.14%。这与坡面轮胎滑移相符；未测接触点精确切向滑移，不能把该比例当完整滑移率。

因此额外欠速不是由“轮子没有给任何驱动力”这一单一解释支持，也不是仅靠更大惩罚就能证明可解决。重力、接触牵引限制与策略的控制反应共同作用；实际总误差中仍有正常起步/爬升耗时。

- 平方权重−1.5、sigma1，有效−1.5e²；指数速度奖励权重1.2。
- 沿用原先指数项误差限幅1m/s，其它门控、奖励以及每策略步一次dt=.02时间缩放不变。
- 不采用后来−2e²，也不采用−2e²(1+|e|/1m/s)。
