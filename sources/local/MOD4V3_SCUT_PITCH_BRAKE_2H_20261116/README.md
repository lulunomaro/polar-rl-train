## 华南虎实际在用什么

以此前窗口所用`rough_rotation_stair/2026-07-23_16-23-21/model_1000.pt`保存的env.yaml为准，源码沿V14→V13→wheelbipe25_v3继承链核对。名称`flat_orientation_y_*`对应重力投影gx，即机身俯仰；不能把腿部theta或名称里的x/y直接当成机身轴。

直接俯仰项为 `-2*((2*exp(-cmd_vx^2/3)+2)*g_x)^2 + exp(-g_x^2/0.02)`，另有`-0.05*(omega_x^2+omega_y^2)`。姿态平方项在零速指令时等效`-32*g_x^2`，2.2m/s指令时约`-11.5*g_x^2`：运行时容许倾斜，停车时更强地回正；指数项从零角度就提供稠密回报，没有5度死区。停车残余线速度为L1项，权重-1；动作一/二阶差分与关节速度项也约束抖动。该权重的速度-直立、速度-高度门控保存为false，不能说靠这些门控取得效果。

我们的基础奖励已含同一组姿态公式和-0.05角速度项，因此照抄无法解释或解决差别。最近新增的3.5角速度惩罚和60倍0.2秒线性预测项没有形成稳定改善；预测状态已被原始轨迹证实高估未来峰值。华南虎自身高速指令跟踪不足、平地急停亦有18.46度，不能把低俯仰当成同速控制优越的证明。

## 本轮实际修改

1. 修复目标环境的速度奖励几何：旧公式`body_vx*cos(pitch)`在有垂直运动/俯仰时不等于世界水平前向速度。以机身重力构造正交水平朝向，替换目标615环境的速度跟踪、速度平方和停车残余速度等原始奖励量，再走原始SCUT状态/权重/日志流程。原速度平方系数-1.5及sigma1保留；35维actor和78维critic输入不改。
2. 取消5度死区、0.2秒线性预测项及额外3.5倍角速度成本。新增成本为`-dt*(0.25*(2*exp(-cmd_vx^2/3)+2)^2*sin(pitch)^2 + 2*(1-exp(-sin(pitch)^2/0.02)) + 0.05*omega_y^2)`。原SCUT基础奖励继续存在。本项在目标环境首次真实接地后持续计入，意外卸载不会豁免。
3. 将本项目既有同状态因果干预转为训练示范：高站姿/高速急停后最初100ms，冻结db6对当前35维观测输出的两个轮动作，按观测轮速方向偏移1并限幅±6。只监督轮动作，系数0.25；腿动作由PPO学习。该标签曾在同一MOD4v3名义反事实实验中把崎岖22.64度降至16.41度、平地18.67度降至15.63度，但不保证蒸馏后复制效果。标签只在停车已经发生后用当前轮速生成；未向部署输入增加阶段/线速度，也未在实际动作输出上叠加控制器。

修改只在本独立目录。其余1433环境保留原综合教师；2048环境、819台阶/717rough/512平地、原fullDR、2.5ms物理、100Hz腿/400Hz轮/50Hz策略、电机包络、2mm单环境闭链guard不变。actor35/critic78/action6合同不变，完整Adam恢复。
