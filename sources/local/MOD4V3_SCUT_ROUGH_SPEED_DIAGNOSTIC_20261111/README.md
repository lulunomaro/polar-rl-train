# 华南虎策略在 MOD4 full DR Rough 下的速度回放

本试验只加载冻结策略，不构造优化器、不更新权重。沿用 R1 回放的 MOD4 资产、2.5 ms 物理步、10 ms PD、20 ms 策略步、TGS32/4、2 mm 单环境闭链重置及完整 DR。

比较对象：当前综合优先 Flat1.5_020m、R1_010m、R1 绝对三次项005m，以及华南虎 rough_rotation_stair/model_1000.pt、rough_dash/model_3500.pt。完整原始参考 PT 保存在 weights/；我们自身 PT 已在此前 Git 档案中保留，本次按 SHA 引用。

每个模型、难度和 DR 条件：8 类 rough 地形 × 正反 1 m/s × 10 个初态，160 环境，20 s。难度 level 0、3 独立执行；nominal 和 full DR 使用同样的初态/对应随机样本。

主要对照窗口是0.5–3s，早于5.5s外力和6s推扰，另列首次episode全段及失败情况；full DR表示完整DR配置，不能把扰动前窗口称为所有环境已受外力推扰。

速度误差直接由重置前真实状态计算：机身 vx，以及华南虎奖励采用的 vx*cos(pitch)。报告 MAE、RMSE、P95、超欠速方向、±0.2 m/s 占比，并明确统计窗口/可用环境数。首次 episode 结束后的状态不混入，提前失败必须同时报告，不把成功越障后的子集当整段成绩。

华南虎原始模型的运行时关节顺序已用原 USD 的 articulation 查询核实（没有物理推进），与我们当前策略顺序一致。关节位移按各自默认位置表示，动作采用默认位置+0.5*a，轮速目标10*a。测试保留 MOD4 控制器和机构限制，并统计统一 ±6 动作裁剪次数。原机器人几何、默认腿角、轮径/控制器及云台与 MOD4 有差异，因此外来权重结果属于直接迁移测试，不能冒充华南虎原机器人的性能。

原始配置见 reference/，实际映射见 REFERENCE_AND_MAPPING.json，执行配方见 PLAN.json，固定权重 SHA 见 MODELS.json 与 PLAN.json。最终结果填写于 REPORT.md。

用户关于加速/爬阶耗时的修正已纳入[瞬态误差解释](TRANSIENT_INTERPRETATION.md)。0.5–3s窗口不能直接称为稳态，进度里程标记也不等于完整障碍出口；本次不依据MAE加大奖励或宣布退化。原解释初稿保留。
