# Rough-v1 轮末固定权重比较

同批比较本轮真实父Rough-v0 100m、轮内代表候选和120m。平地原六项使用原容差及名义/完整DR；Rough-v1使用实际11族地形中的10个非平地族，每族两方向各10初态，代表行0/5/9。行走±1m/s，最高档另看±2.2m/s指令；小陀螺最高档±14.137rad/s；落地以参考允许的4族、可行bank空中出生单独统计。额外保留Rough-v0原最高档回放以对照旧能力。

首次episode只计一次，重置后的表现不补入首次分子。穿越要求2m且实际地形起伏≥3mm；宽台阶每方向5个进台阶、5个出台阶初态，另要求两轮跨过实际高度变化后的清障距离，避免在大平台上走够2m就被记作过阶。旋转同时看首6秒保持和有效窗口MAE。落地把真正离地、接触、姿态与指令连续恢复.5秒分别统计，不把“触地”当“恢复”。

全部回放使用35D actor，完整DR样本/噪声/延迟/推扰对齐；物理/奖励/保护保持训练配方。无优化器更新，不增设新训练准入或100%毕业线。每五分钟本地MuJoCo仅为平地保留筛查，不作为PhysX/fullDR替代。

逐地形遵守训练命令：行走常规±1、高速阶±1.5、落差族±2m/s；2.2高速不强加到仅0.5–1.5的低速宽阶；14.137陀螺仅在实际训练角速范围包含它的5个非平地族检查，不把直行专用地形或限±π的阶坡强加高速陀螺作为通关要求。相应分母为常规穿越200、高速180、旋转100、落地80；原Rough-v0保留测量仍为160。
