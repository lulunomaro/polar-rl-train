# 针对本轮技能取舍的论文与可执行方案（2026-11-13）

本次只检索原论文及作者实现、整理方案；没有修改配方、安装依赖或启动训练。论文元数据、日期、版本和原始地址在SOURCES.json。本文[R1]等对应该文件，论文发现与本项目适配建议分开陈述。

## 当前证据与问题定位

当前40m实验同一V3两阶通过数5m为5/10、40m为0/10；平地前向速度同时逐渐回归，但旋转精度也退化。父iter24692平地60/60，5m候选上阶成功仅集中在0.40m高度指令。本轮父子基础奖励、PPO参数和DR范围相同，主要变化是场景/采样和新增登阶目标。这符合多任务干扰、已有技能遗忘或目标不兼容的表现；目前没有逐任务梯度记录，不能说已经证明了梯度冲突。

奖励速度的cos²俯仰投影低估是已有确定性口径问题；论文方法不会自动修复它。比较新算法前，应让对照组和实验组使用同一、明确的速度定义。平地稳态速度精度与越障过渡过程的速度误差应分项记录，原有门槛范围保持，不把台阶瞬时误差混入平地结论。

## 优先1：训练中持续保留教师指导

依据[R1]、[R5]、[R6]。R1在多任务四足仿真中把教师模仿与PPO结合，在转入强化学习主导阶段后仍保留模仿。R5支持通过经验和行为保留应对遗忘，R6支持训练期间的教师辅助。

以下是我们的适配设计，不是论文已验证的MOD4配方：

- 学生可从本轮5m候选初始化，它尚有可用的登阶动作；健康父iter24692冻结为平地、旋转、站姿和既有rough的行为参考。
- 另冻结5m策略作为局部登阶参考，仅保留在原生训练环境中验证有效的成功状态/片段。已有名义MuJoCo成功适合动作分析，不能直接认作fullDR原生成功专家。
- 平地/既有技能样本向健康父靠拢；成功触阶、收腿、落轮片段向登阶参考靠拢。按真实任务与有效状态范围选择教师，避免在登阶状态硬套平地动作，也避免把5m失败轨迹和严重平地超速一起复制。
- 教师仅在训练端计算指导项，学生网络输入仍35、动作仍6，资产、电机和控制频率无需因此改变。先维持现有训练框架，不整套替换作者工程。

一个可供对照的损失形式为：

`L_actor = L_PPO + lambda_keep * E_Bkeep[||mu_student(o)-mu_parent(o)||^2] + lambda_stair * E_Bstair_success[||mu_student(o)-mu_stair_ref(o)||^2]`

也可以用冻结教师分布的KL作保留项；上式只是清楚展示“长期参考不随学生更新”。这不是新的环境奖励。系数需按本工程损失/梯度实际量级选择，不能把论文数值原封不动搬过来。

PPO自身clip/近邻KL对比的是近期行为策略[R7]，不能替代对固定祖先的长期行为约束。旧示范若用于辅助模仿，应与新鲜PPO rollout分开；R5原算法包含off-policy校正，不能把旧数据当普通on-policy PPO样本。

此方法有用的前提是相应教师在相应状态确实有正确行为。5m不是成熟登阶专家，双教师也不能保证把相互矛盾、不可由当前观测区分的目标无损合并。

## 优先2：按目标分组估值，处理已测得的冲突

依据[R2]。GCR-PPO为不同目标设置价值头、计算优势，并按优先级处理冲突梯度。可借鉴为：速度/转动跟踪、台阶通过/落轮、平滑/能耗分别记录和估值；平地强调跟踪，专项过渡强调通过与稳定。

应先记录不同任务/目标的actor梯度余弦和critic误差，确认冲突位置。R8显示actor与critic的冲突并不总一致，不能看到成绩此消彼长就直接套PCGrad，也不能假定投影梯度必然改善。

这比教师保留改动大：多头critic会改变训练状态结构，不能声称原完整critic/Adam仍原样恢复；但actor的35→6外部接口可以保留。作者实现基于较旧的IsaacLab2.1，应只迁移算法思想和必要模块。

## 优先3：按任务学习状态调整采样

依据[R1]的教师表现差距采样和[R3]的学习进展课程。二者采样信号不同：R1的可选模块偏向学生落后教师的任务；R3使用稳健正向学习进展。不能把它们统称为“失败越多，比例越高”。

本项目可先沿用现有六项平地、两种高度的连续台阶和rough分组，分别追踪保持情况与进展。固定保留份额和自适应份额可作为单独采样实验；此前把固定前进从86增到256的建议属于采样重分配，不等于已经实现这些论文算法。

R3指出仅追逐性能下降可能反复采样噪声/波动任务。因此不建议一遇到0/10就无限提高该任务比例，也不宣称自动课程一定比简单比例好。

## 后续候选：轮腿稀疏多专家

依据[R4]，与机器人形态最接近的工作。它让滚动与抬腿由两个专家和路由器分工。

它的条件与本项目不同：仿真12cm台阶、0.6m/s，使用153维三帧历史观测。不能把该结果宣传成已支持我们的200mm连续两阶、较高指令速度和35维部署契约。多专家内部结构或历史观测可以另立版本研究，当前不优先把现有部署接口大改。

## 推荐的下一步实验顺序

1. 明确并统一速度计算，保留同口径固定平地和V3连续两阶基线。
2. 优先做“有/无持续教师保留”的PPO对照，两边从相同检查点开始，使用相同采样、DR、奖励、预算。采样加量可另做一个对照，不把蒸馏、多critic、自动课程同时放进一轮。
3. 看两个目标能否同时保持：原2.0/2.2m/s平地门槛、两阶成功数和阶间耗时，并检查旋转/站姿/原rough。不能只看总奖励或只看前向速度恢复。
4. 若仍互相压制，依据分任务actor/critic记录决定是否采用R2；再研究R3采样。保留失败和原始轨迹，不为论文方法另设额外物理门槛。

研究结论：现有权重可以继续作为起点和局部教师，不需要先假定全部从零重训。最值得先试的是训练期间的技能保留约束；有效性仍应由本项目父子固定回放决定。
