# 评测口径与可作的比较

本机MuJoCo固定台阶25项：一个入阶面，2.2m/s目标，沿用手动框架0.22s命令平滑；五个正向初态与±15°/±30°各五初态。高度由既有回放方法升至0.42m。真正斜向成绩要求首次第一阶立面接触时偏航仍至少10°，并实际完成两级。

原生PhysX台阶400环境：每模型100名义＋100完整DR，两个入阶面，1.8/2.2m/s，0/±15°/±30°，各五初态；3秒后阶跃目标，原生0.06m/s升高至0.42m；fullDR使用同批机械初态/传感器与力矩噪声、5.5秒外力、6秒推扰作配对。两个模型在此矩阵内同口径比较。

因此只能在各自矩阵内比较父/教师/学生。不能将MuJoCo5/5与PhysX6/20直接当作纯物理引擎差异；矩阵、命令时序和DR条件也不同。本轮报告分开列出这些结果，没有以名义通过代替fullDR毕业。

平地60项为原名义MuJoCo六任务×10初态；原Rough-v1保留是原生最高L9同批名义/完整DR穿越、小陀螺与落地恢复。记录所测条件，不推断未测课程已经毕业。
