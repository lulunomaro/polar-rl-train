## 解释边界

1. 接触力大于 1 N 的比例不是腾空比例。
2. 间隙来自实际 USD 轮凸包输入顶点，相对承重基准计算；不是 PhysX 烹制后的精确接触流形，未扣除接触/rest offset。
3. 支撑点滑移是最低输入网格顶点的速度近似，不是精确接触面滑移。
4. 对完整 30 ms 子步数据取峰值只是检查漏采，不修改当前验收门槛或奖励。
5. 五秒、每档两个环境不能证明十五秒稳定性、DR 或实车鲁棒性。
6. 求解器变化会改变轨迹；同策略对照能检查敏感性，不能单独证明唯一根因。
