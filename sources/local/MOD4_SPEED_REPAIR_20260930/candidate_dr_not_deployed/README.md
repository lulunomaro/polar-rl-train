# 尚未部署的轻度 DR 候选

这些是之前隔离开发的质量/惯量和电机输出倍率 DR 工具，仅供接管审计，不是当前生产训练程序。

质量与惯量同倍率、执行器按episode重采样已在24env/1秒短探针回读通过；新版入口和完整PPO/20k容量/两seed15秒配对尚未全部验收。摩擦、COM、PD、延迟、观测噪声和300–700N力-行程DR尚未完成。

代码已能通过语法检查，acceptance修复空组/NaN/缺失组误判并通过8个纯逻辑例子。该结果不代表运行期训练通过。

已知待修：DR输出倍率会导致computed-applied非零，当前validator不能直接把它当力矩裁剪；先消除倍率影响或记录真正裁剪前后值再评测。旧source_sha256来自旧工作区，安装器对现在修复目录应拒绝；重新审计更新指纹，不能删去校验绕过。

安装器只允许新隔离目录，配置入口要求显式profile。当前生产DR仍关闭。通过子集DR验收也不能宣称完整赛场鲁棒性。
