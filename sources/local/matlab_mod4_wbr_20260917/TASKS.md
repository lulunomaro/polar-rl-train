# 下一步任务与验收清单

## 1. 确认真机数据

- 带电池、云台、弹仓与实际弹药称重，记录载荷配置。
- 分别测左右氮气弹簧的力-眼距曲线、伸/缩方向滞回、阻尼、安装行程和硬止点。
- 测轮胎有效半径、软硬程度、导轮实际尺寸和自由转动阻力。
- 标定输出端扭矩、替换箱效率、转子/减速器惯量、24 V 限速、母线功率与峰值持续时间。

## 2. 控制接口检查

- 核对 x 方向、左右、motor hip/crank 零点与正负号、degree/radian。
- 验证 individual motor limits 与 crank-hip 相对机械限位同时成立，禁止只夹相对角差。
- 先做单轴/支架低能量测试，确认 PD 增益与力矩带宽，再增加运行负载。
- MATLAB 的轴向 KP/KD/KI 与 motor position PD 不可混用；四个腿电机与四个虚拟输入也不可混用。

## 3. 在完整闭链接触模型中复现基础站跑

- 与 MATLAB 对比静态扭矩和安装眼距，确认传动分支与力的符号。
- 记录两个主轮分别的法向载荷、导轮法向载荷、车底/屋顶接触、硬限位冲量。
- 站立和 0.3-1.2 m/s 跑动均验收动作一阶/二阶差分、俯仰/侧倾角与角速度、速度误差、力矩/速度饱和。
- 不用“模型不报错”作为稳定或鲁棒通过标准。

## 4. 氮气弹簧 DR 300-700 N

- 每个环境每次 reset 抽取每支参考力，在 episode 内保持，不每个物理步随意换力。
- 覆盖 300/300、500/500、700/700、300/700、700/300，另做力-行程斜率与阻尼的有依据变化。
- 区分参考力与瞬时力，刚度变化时保持 Fref 定义不变。
- 名义策略不能读取部署时未知的随机参数；如用 privileged critic，应保证 actor 没有该信息。
- 加积分/力估计/RL 负载适应后，仍要验收启动高度峰值、左右不等力 roll、限位接触和狗洞最低净空。

## 5. 特殊地形与高速偏航

- 坡脚/坡顶、起伏、台阶边缘、二级顶面挡圈、飞坡、起跳与落地逐项在真实几何中验收。
- 正弦小陀螺逐级升速，检查横向力、左右载荷转移、roll、轮滑、功率与温升，不能沿用 10 状态模型的成功判定。
- 狗洞使用完整 CAD/碰撞包络；统计全程最小顶隙与通过率，同时保证主轮可用牵引。
- 起跳预算是筛选能力，不是成功任务；补连杆加速、力矩持续时间、实际比赛质量、坡面出射与落地冲击。

## 6. sim2sim / sim2real

- Isaac 与 MuJoCo 共享动作、观测、零点、限位、控制周期、延迟、PD、电机包络与弹簧模型。
- 使用相同指令和随机样本对比状态、输出扭矩、轮载荷与失败原因。
- 名义与极端 DR 样本分别报告，不以均值掩盖最差样本；策略必须在未知弹簧力和实际载荷下过基础站跑门槛。
