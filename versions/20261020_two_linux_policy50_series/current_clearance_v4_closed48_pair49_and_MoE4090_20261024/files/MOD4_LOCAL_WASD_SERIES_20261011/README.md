# MOD4 本地 WASD · 小陀螺与地形系列

双击 `START_WASD.bat`。本地 MuJoCo 物理、100 Hz 冻结策略 CPU 推理。

点击控制面板或仿真窗口后，按住 **W/S** 前后走、**A/D** 左右转，松手减速停车。**空格/X** 立即将指令归零，**R** 复位，**P** 暂停，**F** 切换地形，**M** 切换模型。失去本程序焦点立即归零，不接收其他程序的键盘操作。

**1–7** 分别选择小陀螺 **1、2、4、6、8、10、4π rad/s**。也可用下拉框、按住面板上的方向按钮。原地小陀螺模式禁用直行；定向模式由 W/S 指定世界方向，使用 `BODY vx=2V cos(theta-alpha), V=.5, vy=0`，不做位置纠偏。定向旧训练审查范围为 yaw±1–2；更高档位只是本地试控。

操控面板新增醒目的 **左小陀螺 ⟲ / 右小陀螺 ⟳ / 停车** 按钮。点击小陀螺按钮自动切换原地模式并按所选档位旋转，无需一直按住；点击停车、按空格、切换模型/地形、暂停或失去焦点都会停止。正在运行的旧界面需关闭后重新启动，才能显示新增按钮。

模型下拉框包括：

- **E0 / D7 31903**，SHA `b10958d2…`：冻结的已审平地及小陀螺源，默认模型。
- **地形保留源 / source364 / 32063**，SHA `3c97c14e…`：完整129审查来源；35mm前24/27、倒27/27。
- **独立 E1_WAVE 候选 / source366 / 32068**，SHA `2b4f5a57…`：131前22/27、倒25/27，未合格，保留供手动对照。

每个权重都从已授权4090只读下载，并按完整SHA核验。不会使用同编号但不同SHA的退化检查点。切换模型会复位并清除动作历史；没有动作混合。当前是**手动选择**，MoE gate 尚未训练。

地形下拉框包括：

- 平地。
- **10、20、35 mm** CAD派生起伏，全十波、两端平支撑；35mm局部高度场采样最大误差约0.0207mm。
- **RM V2约70mm** 既有CAD有限采样路段，独立地面调平，并非整场或完成课程。
- **20、35、50 mm跨坎**：竖直侧壁、150mm标记条带连续接上平台；派生测试，不能代替真实RM002高度。
- **5、8、10°坡面**：局部派生测试。
- **20mm×3台阶**：局部人工测试，非已核RM真台阶。

选择“反向起点/下行”会从另一端复位，**W** 沿当前朝向驶入路段。可用近景/全路视角按钮，鼠标拖动和滚轮缩放。出界或倾倒会暂停，按R复位。

跨坎、坡面、台阶当前没有已训练并合格的独立子专家；可用地形源试玩，不能把场景可选当专家已完成。起伏候选也未合格。

本地使用名义MuJoCo适配：0.5ms物理步、31个机器人刚体、6个力矩动作、10项闭链/齿轮约束、35维反馈，沿用实际导入合同与PD/力矩速度包络，没有扶正、航向辅助或teacher。没有复刻PhysX、完整D0–D7随机延迟环境或实物接触。测试记录为本地试玩结果，不是远端课程或硬件验收；本地直行与旋转仍有跟踪残差。

关闭任一窗口退出。重复启动有本地单例锁。旧播放器及其WinError5遥测错误、旧读取惯性主轴速度的结果均保留；新遥测写入有限重试，文件占用不再使播放器退出。

权重与轨迹留在本目录，Git只记录实际路径/大小/SHA；源代码、配置、完整报告与失败版本进入Git。本工具不修改4090/3060训练、预算、课程或监控。
