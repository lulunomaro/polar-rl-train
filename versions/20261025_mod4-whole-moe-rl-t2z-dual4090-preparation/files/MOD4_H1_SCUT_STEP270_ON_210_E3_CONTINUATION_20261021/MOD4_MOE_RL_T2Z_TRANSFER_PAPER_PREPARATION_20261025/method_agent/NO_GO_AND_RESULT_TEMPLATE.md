# Whole-MoE no-go and result schema

All decisions here concern a **new research stage** only. They do not add physical health gates to current production or authorize its interruption. Existing2.5ms/TGS32/4 choice, per-environment2mmclosure reset, actual finite/integrity/hardware/save protection and original task evaluators remain unchanged. No FP64/bitwise/1µm blanket gate is added.

| Condition | Stage classification | Consequence |
|---|---|---|
| existing H1 not complete / collector or resource ownership active | `WAIT_ACTUAL_RELEASE_NO_TRAIN` | prepare source and archive; root serial coordination governs actual handoff |
| native whole-stack RGB/plan/applied/routing/clock receipts absent | `DATASET_MISSING` | no training; synthetic examples remain examples |
| only old GUI playback or selected H1short traces exist | `NOT_CERTIFIED_TRAIN_DATA` | retain descriptive provenance; do not call them complete native mixed-RL data |

| future actual action/gate/apply receipt enters selector | `PRIVILEGED_FUTURE_INPUT` | diagnostic only; main candidate path uses committed commands/routes |
| hidden delay inferred from future application timing | `INVALID_COMMAND_CAUSALITY` | command-conditioned branch only |
| no independent task/contact observer or actual outcome evaluator | `PHYSICAL_METRIC_NA` | no skill/physical success claim from video similarity |
| macro improves while one task/worst domain degrades materially | `NO_WHOLE_STACK_UTILITY_EVIDENCE` | publish per-task/worst-domain negative result; no averaging-away failure |

| real dependency import/Wan shape/weights/z-freeze checks pending | `INTEGRATION_PENDING` | CPU stub path is insufficient for training readiness |
| per-device OOM/time/disk/approved budget exceeded | `RESOURCE_NO_GO` | preserve config/error/cost; no unbounded retries or budget borrowing |
| model nonfinite, timeout, native unknown termination | explicit failed/missing case | retain denominator and original reason |

Prospective utility criterion to freeze before test access: at least10%improvement in the five-task macro physical prediction endpoint relative to matchedStandard, positive paired group-CI, same effect direction across three seeds, and no prespecified material task/worst-domain/contact degradation. Exact task normalizers and noninferiority margins require validation/power review before test unsealing; this document does not pretend they are already approved or measured. Near-zero baseline error makes relative improvement undefined; report absolute differences andNAutility. There is no candidate/whole-MoE success claim before actual execution.

The prior H1-specific utility rule is not silently reused as a whole-system safety threshold. Real task success remains each original criterion, including actual double-wheel270mmcontact/recovery forH1. Currentmanifest skill_qualification=false and oldrouting negatives remain visible.
